🚀 SmartGymBro — Guía Rápida de Despliegue e Integración

Práctica Integradora Final (HIA 2026) · Manual Operativo para el Equipo
DevOps: Aldo Dante Rama: feature/setup-unificado Docker Compose Maestro
⚠️ Requisito previo fundamental: Asegurarse de tener Docker Desktop iniciado y corriendo en la máquina antes de ejecutar los comandos.

1️⃣ Clonar o actualizar el repositorio

Abrí una terminal (PowerShell, Git Bash o CMD) y posicionate en la rama unificada:

git clone https://github.com/GonzaloAPU/tp-Final-Gymbro.git
cd tp-Final-Gymbro
git checkout feature/setup-unificado

(O git checkout develop una vez que el PR sea aprobado).

2️⃣ Generar los archivos de entorno (1 Clic)

Desde el Explorador de Windows, hacé doble clic en la raíz del proyecto sobre:

👉 00_preparar_entorno.bat

Crea y sincroniza automáticamente todos los archivos .env con las contraseñas estándar del equipo (admin123), sin exponer secretos en Git.

3️⃣ Levantar el stack completo de contenedores

En la consola parada en la raíz del proyecto, ejecutá:

docker compose up -d

Levanta en paralelo: Frontend, Backend API, PostgreSQL Primario, Réplica Streaming, Backups automáticos, pgAdmin, Nextcloud y Mantis Bug Tracker en la red unificada gymbro-net.

4️⃣ Poblar Base de Datos, Índices e Incidencias (3 Clics)

Hacé doble clic en los siguientes ejecutables en orden:

A. Carga masiva (Punto 4): postgres\01_poblar_base_datos.bat
Puebla 20.000 usuarios atletas y 6.000.000 de pesajes en memoria. (Toma ~9 minutos; no cerrar la ventana hasta que finalice).

B. Optimización SQL (Punto 5): postgres\02_aplicar_indices_optimizacion.bat
Aplica los 8 índices B-Tree, parciales y de cobertura en ~5 segundos.

C. Incidencias Mantis (Punto 11): infra\incidencias\01_restaurar_mantis.bat
Restaura el backup con las 10 incidencias de auditoría cargadas por Rodrigo.

5️⃣ Levantar Monitoreo (Punto 10)

Para encender el panel de métricas con Prometheus y Grafana:

docker compose -f infra/monitoring/compose.yaml up -d
