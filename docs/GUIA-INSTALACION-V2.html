🚀 SmartGymBro — Guía de Instalación Versión 2.0

Práctica Integradora Final (HIA 2026) · Manual Integral de Despliegue Local y Remoto
Líder DevOps: Aldo Dante Antivilo Versión 2.0 Definitiva Cluster: Core + Monitoreo + n8n
📌 Prerrequisito indispensable: Tener Docker Desktop iniciado y corriendo en la máquina (icono verde abajo a la izquierda "Engine running") y Node.js v20/v22 instalado en Windows.

1️⃣ Clonar o actualizar el repositorio

Abrí una terminal (PowerShell, Git Bash o CMD) y posicionate en el repositorio:

git clone https://github.com/GonzaloAPU/tp-Final-Gymbro.git
cd tp-Final-Gymbro
git checkout develop

Si ya tenés el repositorio clonado, asegurate de tener la última versión con: git pull origin develop

2️⃣ Generar los archivos de entorno .env (1 Clic)

Desde el Explorador de Windows, hacé doble clic en la raíz del proyecto sobre:

👉 00_preparar_entorno.bat

Este script genera automáticamente los 5 archivos .env sincronizados (raíz, backend, postgres, monitoring y n8n) sin exponer secretos a Git.

⚠️ Tip clave antes de poblar: En la raíz del repositorio ejecutá:
npm install
Esto garantiza que las dependencias de Node.js (como dotenv y pg) estén listas para los scripts.

3️⃣ Levantar el stack principal de la aplicación

En la consola parada en la raíz del proyecto, ejecutá:

docker compose up -d

Inicia los 8 servicios principales: Frontend Angular (:4300), Backend API (:3100), PostgreSQL 17 Primario (:55433), Réplica Hot Standby (:55434), Backup Daemon, pgAdmin 4 (:5051), Nextcloud (:8081) y Mantis Bug Tracker (:8089).

4️⃣ Poblar Base de Datos (6.000.000 de Series) e Índices SQL

Podés elegir cualquiera de las dos opciones para poblar la base de datos de forma completa:

Opción A: Mediante Ejecutables Batch (Doble Clic)

1. Carga Masiva (Punto 4): postgres\01_poblar_base_datos.bat (Genera 20.001 atletas, 500k sesiones, 2M ejercicios y 6M de series en gymbro.series_realizadas + 100k pesajes de control).

2. Índices de Optimización (Punto 5): postgres\02_aplicar_indices_optimizacion.bat (Crea los 8 índices B-Tree compuestos).

3. Restaurar Incidencias (Punto 11): infra\incidencias\01_restaurar_mantis.bat

Opción B: Mediante Terminal (Comandos Directos recomendados)

Si tu sistema operativo tiene restricciones con archivos .bat, ejecutá en la raíz:

node postgres\seed-actividad.mjs
node postgres\seed-6m.mjs
docker exec -i gymbro-postgres-primary psql -U smartgymbro_tp -d smartgymbro_tp < postgres\indices.sql
docker exec -i mantis-mysql-db mysql -u mantis_user -pmantis_password_seguro bugtracker < infra\incidencias\mantis_backup.sql

5️⃣ Levantar Monitoreo y Métricas (Sonia - Punto 10)

Para encender el panel de observabilidad independiente con Prometheus y Grafana:

docker compose -f infra\monitoring\compose.yaml up -d

Levanta Prometheus (:9090), Grafana (:3001), cAdvisor (:8080), Node Exporter (:9100), Postgres Exporter (:9187) y Blackbox Exporter (:9115).

6️⃣ Levantar Automatizaciones con n8n (Sonia - Punto 13)

Para inicializar el motor de flujos automatizados (Alertas, Backups, Informes IA y Restauración controlada):

cd infra\n8n
powershell -ExecutionPolicy Bypass -File .\sembrar-n8n.ps1

Siembra e importa automáticamente los 4 workflows en n8n (:5678), conecta el analizador IA y crea el contenedor aislado de prueba de restauración (pg-restore-test).

🛠️ Preguntas Frecuentes y Solución de Problemas (Troubleshooting)

1. ¿Qué base de datos debo poner en DBeaver / DataGrip?
El nombre de la Base de Datos física es smartgymbro_tp. Adentro vas a ver el esquema gymbro con las tablas y las 6 millones de series. No uses gymbro como nombre de base porque te dará error de base inexistente.

2. Error "Cannot find package dotenv" al ejecutar los seeders:
Abrí una terminal en la raíz de tu repositorio y corré npm install para instalar las dependencias generales.

3. En Nextcloud me sale "Acceso a través de un dominio del que no se confía":
Si accedés por Tailscale o por una IP personalizada, ejecutá dentro del contenedor de Nextcloud:
docker exec -u www-data gymbro-nextcloud php occ config:system:set trusted_domains 8 --value="TU_IP"
